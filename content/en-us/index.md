# Nodezator

Nodezator is a multi-purpose node editor for the Python programming language. It takes your functions (or other callables) and turns them into Python nodes, allowing you to create and execute complex node layouts and even export them back as Python code.

<img class="mx-auto d-block img-fluid mb-4" style="width:960px" src="https://i.imgur.com/lFjcSS4.png" alt="Nodezator screenshot" />

## Install or use as a standalone app

To install the app, use the <code>pip install nodezator</code> command. After this you can launch Nodezator with the <code>nodezator</code> command.

You don't need to install if you don't want though. To use it without installing, first download the source from [GitHub](https://github.com/IndieSmiths/nodezator) <i class="fa fa-github icon20px" style="color:white;"></i>. You'll only need the "nodezator" folder in the repository top directory. You can now launch the app right away by executing <code>python -m nodezator</code> (or <code>python3 -m nodezator</code> depending on your system) in the location where the "nodezator" folder is, as long as you have the [pygame-ce](https://pyga.me) and [numpy](https://numpy.org) libraries installed.

Regardless of whether you install or use Nodezator as a standalone app, your best next step probably is to become acquainted with the <a href="https://manual.nodezator.com">manual</a> <span class="icon20px">🧐</span>: it was made with lots of love <span class="icon20px">🥰</span>
