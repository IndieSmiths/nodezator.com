# Nodezator

Nodezator é um editor de nós multipropósito para a linguagem de programação Python. Ele pega suas funções (ou outros objetos chamáveis) e as torna em nós Python, permitindo que você crie e execute layouts de nós complexos e até mesmo os exporte de volta como código Python.

<img class="mx-auto d-block img-fluid mb-4" style="width:960px" src="https://i.imgur.com/lFjcSS4.png" alt="Captura de tela do Nodezator" />

## Instale ou use como um app standalone/auto-suficientes

Para instalar o app, use o comando <code>pip install nodezator</code>. Depois disto você pode iniciar o aplicativo com o comando <code>nodezator</code>.

Você não precisar isntalar se não quiser, no entanto. Para usar sem instalar, primeiro baixe o código-fonte do [GitHub](https://github.com/IndieSmiths/nodezator) <i class="fa fa-github icon20px" style="color:white;"></i>. Você só precisará da pasta "nodezator" no topo da pasta do repositório. Você pode iniciar o aplicativo logo depois por meio da execução de <code>python -m nodezator</code> (ou <code>python3 -m nodezator</code>) dependendo do seu sistema) no local onde a pasta "nodezator" se encontra, contanto que você tenha a bibliotecas [pygame-ce](https://pyga.me) e [numpy](https://numpy.org) instaladas.

Independente de instalar ou usar Nodezator como um app standalone, seu melhor próximo passo é se familiarizar com o <a href="https://manual.nodezator.com">manual</a> <span class="icon20px">🧐</span>: foi feito com muito amor <span class="icon20px">🥰</span>
